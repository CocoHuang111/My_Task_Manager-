## 三、个人反思
我看到PPT里写着“项目分解与多步开发”：
- 确认项目骨架，整体结构以及目录结构
- 开发核心功能：任务列表与清单
- 数据持久化
- 开发看板视图，以及前端交互逻辑
感觉第一次跟ai的交互过程很重要，决定了项目的根基，所以不太清楚老师是否鼓励我们按照这个步骤逐步开发而不是一开始就把所有的功能和要求都告诉ai？
如果逐步开发的话看起来要后续修改增补很多重要的接口，感觉更容易出错；如果一开始就把所有的功能和要求都告诉ai的话，ai会不会因为要实现的功能太多太复杂而在其中丢三落四生成一些开发阶段不易察觉的问题？agent第一次搭建做到什么样的程度就可以了呢？
